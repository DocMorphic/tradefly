# Two independent flies

The local worker now defaults to `--flies 2`. Each process owns a full validated FlyWire v783 brain, its private random generator, neural state and checkpoint. Both begin as copies of the previously saved shared brain; different input sequences then make their states diverge. This is a change in experiment design, not a faster implementation of the same single-brain history. Model equations, weights, sensory encoding and neural action decoding are unchanged. The scheduling design follows Brian2's [independent simulation guidance](https://brian2.readthedocs.io/en/stable/user/computation.html); Tradefly uses process-local Cython runtime simulations.

A single coordinator visits the complete Alpaca US-equity universe in the existing stable hash order and assigns the next usable stock to an idle fly. No market score picks the stock or overrides the neural action. Input bars remain five minutes long; there is no five-minute sleep between stocks. Up to sixteen unavailable-data symbols can be skipped per dispatch without sleeping between each gap. A fly that finishes first can receive another stock without waiting for its peer.

Only the coordinator accesses the broker and SQLite ledger. It refreshes account state, reconciles existing orders, checks input freshness and desktop control, and applies the existing $100 order and 10% **total account** exposure limits before sending one order at a time. A pause invalidates queued intents and any currently calculating decision for execution. Completed calculations can still be recorded after pausing. Old or delayed intents are discarded instead of traded against a newer bar. No worker directly places orders.

Checkpoints live in ignored `runs/flies/fly-1.checkpoint` and `fly-2.checkpoint`. Each worker atomically replaces its own checkpoint before returning a result. A durable coordinator marker precedes dispatch and remains until the decision is recorded. An interrupted worker or inconsistent checkpoint pauses the experiment and requires recovery; do not manually clear the marker to force trading. The original `runs/brain.checkpoint` is preserved. `--flies 1` selects the old shared-brain implementation and its preserved state; it does not merge or continue either independent fly's history.

The Evidence desk's Market map shows each fly's current stock, completed evaluations, queue size and evaluations per minute since resume (paused time excluded). This rate includes time waiting on market data and orders. Decision inspector, Fly log and Brain activity label new results by fly ID. Older records have no fly label because they came from the single-brain run.

## Measured local benchmark

On this 6-core, 8 GB Mac, an isolated warm benchmark performed four 500 ms calculations with recording and checkpoint saves. One fly took 10.54 s; two parallel flies took 7.60 s: 1.39× computational throughput, about 28% less elapsed time. This does not measure end-to-end market scanning speed, predict profitability, or imply a whole-market scan every five minutes. Market availability, API latency, order reconciliation, memory contention and workload affect the final rate. Flies are capped at two in this local implementation; more requires another benchmark or a larger host.

Reproduce with `uv run python scripts/benchmark-fly-pool.py`. It uses temporary checkpoint copies, never imports a broker, never places orders, and writes its report to ignored `runs/pool-benchmark.json`. Exclude cold compilation from comparisons. Production starts paused after every restart.
